# Аудит полноты каталога — 2026-09-20

План работ, неделя 2: «проверка сборщиков РТУ и остальных на потерянные
страницы». Инструмент повторяемый: `pipeline/src/audit_completeness.py`.

## Метод

Независимый источник — государственная база **NIID.lv** (учреждения вносят
данные сами). Для каждого из 22 вузов взяты все программы NIID по трём
уровням (`level_1` = 7 бакалавриат и короткие программы, 8 магистратура, 9
докторантура) и сравнены по уровням с числом уникальных программ в нашем
каталоге (lv/en-варианты и города считаются за одну). Названия у NIID
латышские, у части наших строк английские, поэтому сравниваются числа, а
не имена; небольшое расхождение — норма (NIID пишет отдельную запись на
форму обучения и язык), искать нужно большие дыры.

Ходили на niid.lv по правилам `polite.py` (пауза 10 с по `robots.txt`
сайта), полный прогон — около 45 минут.

## Причины

1. **Сборщики читают английские разделы сайтов** (LBTU, DU, Turība), а в
   них нет программ, которые ведутся только по-латышски. Для аудитории А
   (латышские выпускники) это как раз основная масса программ.
2. **РТУ** (исправлено): реестр РТУ сборщик читал целиком, но сознательно
   пропускал программы в нескольких городах («общую квоту честно не
   делим»), программы только в Лиепае сверх трёх отобранных вручную и
   шесть морских программ Latvijas Jūras akadēmija без города — 36 из 157
   строк, среди них «Datorsistēmas» (200 бюджетных мест). Теперь строка на
   каждый город (число бюджетных мест пустое при общей квоте), 124 → 163
   строки, старые ключи не менялись.
3. У RISEBA и RSU не собраны магистратура и докторантура (сборщики
   смотрят на бакалавриат и часть других разделов).
4. Проверка порогов в `main.py` этого не ловила: она ловит **снижение**
   числа программ, но не то, чего сборщик не видел с самого начала.

## Варианты закрытия (решение за владельцем)

| | A. Добор из NIID | B. Расширить сборщики на латышские страницы | C. Заменить сборщики этих вузов на NIID целиком |
|---|---|---|---|
| Что | один общий сборщик, добавляет программы NIID, которых у нас нет | по 2–4 ч на вуз: LBTU, DU, Turība, RISEBA, RSU | как уже сделано для ViA и колледжей |
| Объём | 5–8 ч на всё | 10–20 ч | 3–4 ч |
| Данные | язык, форма, срок, цена, финансирование; названия только латышские; ссылка ведёт на NIID | лучшие: число бюджетных мест, ссылка на страницу вуза | как у A, но пропадают английские строки с бюджетными местами |
| Риск | дубли: у NIID имена латышские, у наших строк английские — нужен явный список «уже покрыто» по каждому вузу | вузовские сайты меняются, поддержка дороже | потеря уже собранных данных |
| Рекомендация | **да**, для LBTU, DU, Turība, RISEBA, RSU; правило: добавлять записи NIID только на латышском, английские сверять по списку «уже покрыто» | точечно позже, для вузов, где нужны бюджетные места (после подтверждения формул) | нет |

Чем жертвуем при A: у добавленных программ не будет числа бюджетных мест
(его нет в NIID; есть только «государственный бюджет или платно» → тип
финансирования), и карточка ведёт на NIID, а не на сайт вуза. Число мест
человек всё равно подтверждает по документам вуза (правило 6 `CLAUDE.md`).
