## 1. Что это и для кого

**StudyPick** (`studypick.eu`) — веб-сервис, который помогает выбрать вуз и
программу. Одна база (программы, требования, сроки, стоимость) и две
аудитории, которые строятся **строго по очереди**:

| | Аудитория А — местные выпускники | Аудитория Б — иностранные абитуриенты |
|---|---|---|
| Очередь | первая, сейчас | вторая, после сезона 2027 |
| Вопрос | «Что мне подходит и куда я реально прохожу?» | «Во что обойдётся год и что нужно собрать?» |
| Продукт | анкета → каталог → расчёт конкурсного балла → живой конкурс в дни подачи | полная стоимость, чек-листы документов, предпроверка комплекта, путь к ВНЖ |
| Деньги | бесплатно, канал роста | платно (Stripe Payment Links) |

**Три страны** (решения владельца 2026-10-05 и 2026-10-11):

| Страна | Статус | Дата открытия |
|---|---|---|
| Латвия | основная, всё строится для неё первой | **5 января 2027** (Turība открывает приём) |
| Литва | полный паритет с Латвией, закрыта флагом предпросмотра | **1 июня 2027** (основной приём LAMA BPO) |
| Эстония | строится, закрыта флагом предпросмотра | даты нет |

Разработчик один (~8 ч кода в неделю), бюджет инфраструктуры до €50/мес.
**При отставании режем охват, а не качество**; латвийские даты
неприкосновенны — первой останавливается Эстония, потом Литва.

## 3. Что видит пользователь

### Адреса и языки

Первый сегмент адреса — «язык-страна»; у языка самой страны суффикса нет.
Четыре языка интерфейса у каждой страны, переключатель **LV · LT · ET ·
EN** в шапке (сохраняет фильтры каталога), страна — в подвале.

| | Латышский | Литовский | Эстонский | Английский |
|---|---|---|---|---|
| Латвия | `/lv` | `/lt-lv` | `/et-lv` | `/en-lv` |
| Литва | `/lv-lt` | `/lt` | `/et-lt` | `/en-lt` |
| Эстония | `/lv-ee` | `/lt-ee` | `/et` | `/en-ee` |

Без флага предпросмотра (`NEXT_PUBLIC_PREVIEW_COUNTRIES=1`) открыты только
`/lv`, `/lt-lv`, `/en-lv`; Литва, Эстония и весь эстонский язык закрыты.
`/` ведёт на язык браузера. Названия и описания программ — на языке
источника, с пометкой; длинные тексты (словарь, права, политика)
переведены на все четыре языка (перевод не носителя, с оговоркой «при
расхождении действует оригинал»).

**Тон текстов** (решение 2026-10-11): латышский и эстонский — безлично,
литовский — на «jūs», английский — на «you»; заголовков от первого лица нет.

### Карточка программы

Уровень, язык, форма, срок («1 gads», «4,5 gadi»), город, финансирование,
цена, бюджетные места, сроки подачи, тип отбора, аккредитация, ссылка на
источник и **метка происхождения**: «проверено вручную <дата>» или
«извлечено автоматически — сверьтесь с сайтом вуза». Блок «Что с
выпускниками» — только при подтверждённом направлении. У литовских программ
— прошлогодний конкурс и выпускники направления. У эстонских — направление,
срок подачи (действующий или прошлого приёма), условия конкурса SAIS и
правило конкурса: у Тартуского университета — из чего складывается балл и
пороги («для подачи ≥ 66», «место гарантирует > 80»), у TalTech — минимумы
по госэкзаменам и число мест. Без расчёта и без вывода о человеке. SEO:
canonical, hreflang, `x-default`, meta description, JSON-LD (с
экранированием `<`).

### Калькулятор и обратный поиск

Один вычислитель для всех латвийских вузов (`src/lib/formula.ts`); всё, чем
вузы различаются, — строки в таблицах:

```
балл = Σ (результат_CE% × k_уровня × k_предмета)
     + средний_% по всем CE × k_среднего
     + вклад аттестата + вступительное испытание × k
```

Коэффициенты уровня: `augstākais 1,00 · optimālais 0,75 · vispārīgais 0,50`.
**Уровень каждого экзамена выбирается обязательно** (решение 2026-10-16:
раньше по умолчанию стоял высший, и балл завышался). Разбор под итогом
показывает запись слагаемого «72 % × 0,75 × 1,5 = 81,00»; итог объявляется
экранному диктору. Шкалы у вузов разные — баллы несравнимы, рядом
прошлогодние цифры конкурса без оценки шансов, ссылка на правила приёма и
оговорка, что решает вуз. В `/match` длинные группы «чего-то не хватает»
свёрнуты. Расчёт идёт в браузере, результаты экзаменов никуда не
отправляются и не попадают в адрес.

### Доверие к фактам

- **Правило 6 (Латвия):** формулу, срок подачи, стоимость и бюджетные
  места, языковое требование и канал подачи подтверждает только человек.
  Конвейер никогда не ставит `verified_at`; изменение подтверждённого поля
  при новом сборе снимает подтверждение (`catalog_diff.py`).
- **Литва и Эстония** — исключение по решению владельца: факты без
  подтверждения, с пометкой «извлечено автоматически», датой и ссылкой.
- **Направления** подтверждаются **по правилу**, а не по строке (ошибка
  стоит дёшево — не тот фильтр интересов): владелец утверждает набор
  правил и каждую новую партию.
- **Формулы** берутся из утверждённого PDF правил приёма; у каждой — номер,
  дата и копия документа (`docs/source-documents/`), без них база не даст
  подтвердить. Спорный факт помечается отдельно (`disputed_at`).
- Языковая модель извлекает и объясняет, но **не является источником факта**.

## 5. Архитектура и стек

```
Next.js 16.4 (App Router)                       Python 3.13 + Playwright + pydantic
  ├─ публичные страницы: серверные,               │  сборщики → проверка полноты →
  │  Tailwind, без HeroUI                          │  сравнение с базой → запись
  ├─ интерактив (анкета, калькулятор,             │  сервисным ключом
  │  обратный поиск): HeroUI v2 + провайдер        │
  │  только вокруг формы                           │
  └─ каталог из памяти сервера (5 мин)            │
                   └──────────────┬───────────────┘
                                  ▼
                   Supabase (Postgres, ЕС) — RLS на каждой таблице
```

| Слой | Что |
|---|---|
| Веб | Next.js 16.4.2, React 19.2.9 (срочное обновление безопасности 2026-10-17) |
| UI | HeroUI **v2** + Tailwind v4 |
| База | Supabase, регион ЕС |
| Хостинг | **свой сервер владельца** в ЕС (Ubuntu 24.04): Caddy (HTTPS, журнал запросов 14 дней) → сайт как служба systemd; `deploy/` |
| Аналитика | PostHog ЕС **своим кодом, без их библиотеки** (`src/lib/analytics.ts`): просмотры страниц, три события (анкета пройдена, балл показан в калькуляторе и в обратном поиске), скорость страниц (Core Web Vitals); без cookies, без хранения в браузере, без IP |
| Почта | Gmail `studypickeu@gmail.com` (письма об ошибках, запросы по данным); Resend — с января, не подключён |
| Платежи | Stripe Payment Links — с выпуска 4 |

Главные решения:
1. **Многоязычность с первого коммита:** тексты только в
   `src/i18n/dictionaries/*.json` (4 основных словаря + 8 файлов отличий по
   странам); язык и страну из адреса дают `languageOf` и `countryOf`.
2. **Формулы — данные, а не код.**
3. **Граница Next.js / Python — по базе**, без HTTP-API между ними.
4. **Публичные страницы лёгкие** (~145 КБ сжатого JS, из них 112 —
   React и Next.js); HeroUI только в интерактивных формах.
5. **Чистая логика отдельно от запросов к базе** (`formula.ts` /
   `formula-queries.ts`, `catalog-view.ts` / `catalog-query.ts` и т. п.) —
   тестируется без Supabase.

## 6. Конвейер данных

- `python src/main.py` — латвийские источники; по имени — выборочно.
  Проверка полноты: если источник нашёл заметно меньше программ, чем
  раньше, запись не делается. Подтверждённое не затирается.
- Вежливый обход (`polite.py`): честный User-Agent, паузы между страницами,
  `robots.txt` соблюдается, картинки не грузятся.
- **По расписанию на GitHub:** Латвия — по понедельникам
  (`scrape-catalog.yml`), обогащение из NIID — 2-го числа; Литва — 3-го
  числа и по четвергам в июне–августе; Эстония — 4-го числа и по вторникам
  в марте–августе (`ee_refresh.py`). Часть латвийских сайтов отвечает
  только с домашнего адреса — их сбор с компьютера владельца
  (`main.py --local`), напоминание раз в неделю.
- **Сторожа** (письмо от GitHub при падении): латвийский сбор не прошёл
  9 дней, литовские или эстонские данные старше 45 дней.
- **Копии:** подтверждённые факты — в репозиторий раз в неделю
  (`docs/backups/`), полная копия базы — артефакт на 14 дней.

## 7. Качество

**Безопасность (OWASP Top 10:2025).** RLS везде, запись публичным ключом
запрещена; сервисный ключ только у конвейера; защитные заголовки
(`next.config.ts`: запрет встраивания во фрейм, `nosniff`,
`Referrer-Policy`, `Permissions-Policy`, HSTS); каждая зависимость
обосновывается; своей авторизации нет. 17 октября — срочное обновление
Next.js и React из-за критических уязвимостей от 14 октября.

**Доступность (WCAG 2.2 AA).** axe-core на ~120 адресах всех стран и
языков, клавиатурный проход анкеты и калькулятора на шести языковых
вариантах, видимый фокус; живые области для балла; имена у всех групп
ответов анкеты; на телефоне страница без прокрутки вбок, поля от 16 px.

**Скорость.** Цели `LCP < 2,5 с`, `INP < 200 мс`, `CLS < 0,1` меряются у
настоящих посетителей (PostHog, отчёт «Web vitals»). Каталог — из памяти
сервера и страницами по 24.

**Проверки:** 285 модульных тестов (vitest), 134 сквозные проверки
(Playwright), самотесты конвейера, сборка — в CI на каждый push. Пробный
прогон предрелизных проверок — `docs/checks/PRERELEASE-2026-10-16.md`.

## 8. Как работать с проектом

```bash
npm run dev               # локальный сервер, http://localhost:3000
npm run build             # рабочая сборка
npm run lint
npm run test              # модульные тесты
npm run test:a11y         # сквозные проверки (после сборки)
```

Окружение сайта — `.env.local` (шаблон `.env.local.example`); для Литвы и
Эстонии локально — `NEXT_PUBLIC_PREVIEW_COUNTRIES=1`. Окружение конвейера
— `pipeline/.env`. Выкладка — `deploy/README.md`, обновление на сервере —
`deploy/update.sh`. До запуска сайт закрыт (`SITE_CLOSED=1`: запрет
индексации, пароль Caddy).

Порядок работы (из `CLAUDE.md`): сначала план, потом код; маленькие шаги;
предлагать простое и говорить, чем жертвуем; перед новой библиотекой —
сколько весит и что будет без неё.

## 9. Известные ограничения

- **Латвийские факты для подачи подтверждены частично:** формул 75,
  требований 332, типов отбора 16; сроки и каналы подачи — ждут владельца.
- **РТУ:** формулы есть у 2 программ из ~220; направления по программам —
  вопрос в письме комиссии (писем восемь, не отправлены).
- **Язык по допущению** у пяти вузов (EKrA, JVLMA, LMA — латышский; RGSL,
  SSE Riga — английский), подтверждённый NIID.
- **Литва:** нет сроков 2027, магистратуры и цен (источники не дают).
- **Эстония:** цены только у части конкурсов SAIS; калькулятора нет (ждёт
  правил приёма на 2027/28; решение о «порог пройден» принято 2026-10-25); TLÜ не разобран
  (испытание вуза есть у всех специальностей).
- **Gmail** — самостоятельный оператор переписки, договора о защите
  данных с Google нет (решение владельца 2026-10-16, сказано в политике).
- **Переводы** на литовский и эстонский — не носителя; вычитка рекомендована.
- Кэша страниц нет (ответ 160–280 мс — не мешает).
