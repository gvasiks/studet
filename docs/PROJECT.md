## 1. Что это и для кого

**Studet** — веб-сервис, который помогает выбрать вуз и программу в Латвии.
Одна база данных (программы, требования, сроки, стоимость) и две аудитории,
которые строятся **строго по очереди, а не параллельно**:

| | Аудитория А — местные выпускники | Аудитория Б — иностранные абитуриенты |
|---|---|---|
| Очередь | первая | вторая |
| Язык | латышский | английский |
| Вопрос | «Что мне подходит и куда я реально прохожу?» | «Во что обойдётся год и что нужно собрать?» |
| Продукт | анкета → каталог → расчёт конкурсного балла → живой конкурс в дни подачи | полная стоимость, чек-листы документов, предпроверка комплекта, путь к ВНЖ |
| Деньги | бесплатно, канал роста | платно, выручка (Stripe Payment Links) |
| Статус | в работе | не начата |

Разработчик один (~12 ч/нед, из них ~5 на код), бюджет инфраструктуры до
€50/мес. Отсюда главный принцип: **при отставании режем охват, а не
качество** — два вуза точно лучше восьми приблизительно.

### Три даты выпуска

| **Январь 2027** | Анкета + каталог (частные вузы целиком + государственные) | Turība открывает приём 5 января |
| **Май 2027** | Калькулятор конкурсного балла (ЛУ, РТУ, Вентспилс) | Месяц запаса до сезона |
| **9–20 июля 2027** | Сезон подачи: живой конкурс, список приоритетов, 2-й тур 27–29 июля | Внешняя непереносимая дата |

## 3. Что видит пользователь

Обе локали (`/lv`, `/en`) есть на каждом маршруте. Переключатель языка в
шапке. `/` перенаправляет на язык браузера (`src/proxy.ts`).

| Маршрут | Что там |
|---|---|
| `/` | Главная: тёмная сцена с фоновой картинкой, призыв пройти анкету |
| `/programmes` | Каталог: поиск, сортировка, вкладки уровней, фильтры (вуз, город, язык, форма обучения, только бюджет, интересы), «показать ещё» |
| `/programmes/[university]/[programme]` | Карточка программы — главная страница для поисковой выдачи |
| `/programmes/[university]/[programme]/calculator` | Калькулятор конкурсного балла (виден только при подтверждённой формуле) |
| `/survey` | Анкета из 6 шагов, ведёт в каталог с готовыми фильтрами |
| `/favorites` | Избранное и сравнение — только в `localStorage`, без регистрации |
| `/verification` | Внутренняя очередь на подтверждение (`noindex`, только на латышском) |
| `/sitemap.xml`, `/robots.txt` | Карта сайта из базы и правила для роботов |

### Каталог

- Состояние фильтров живёт **в URL** (`?level=…&city=riga&q=…`), страница
  серверная, JS для фильтрации не нужен. Мобильные фильтры и выпадающий
  список сортировки сделаны на чистой разметке без клиентского кода.
- **Карточка** программы: уровень, название, вуз, язык, **город**, срок,
  ближайший срок подачи, звезда избранного. Город — свой у каждой программы
  (важно для филиалов: одна программа Juridiskā koledža идёт в пяти
  городах).
- Счётчик в шапке: «899 программ · 44 учреждения» (колледжи — не
  «augstskolas», поэтому надпись про «iestādes / institutions»).
- Города каталога: Rīga, Daugavpils, Valmiera, Ventspils, Jelgava,
  Liepāja, Rēzekne, Jūrmala, Gulbene, Malnava.

### Карточка программы

Уровень, язык, форма, срок, город, финансирование, цена за год (для
ЕС/ЕЭЗ), число бюджетных мест, сроки подачи, тип отбора вуза (конкурсный
балл / вступительные испытания / открытый приём / собеседование), дата
аккредитации, ссылка на официальный источник и **метка происхождения
данных**: «проверено вручную <дата>» или «извлечено автоматически —
сверьтесь с сайтом вуза».

Блок **«Что с выпускниками»** (занятость и доход) показывается только если
направление программы подтверждено человеком: черновая классификация по
названию не должна давать зарплатные цифры (см. раздел 4).

Есть SEO-разметка: canonical, hreflang, `x-default` на латышский, meta
description, JSON-LD.

### Анкета

Шесть вопросов про **ограничения, а не про личность**: какие экзамены
сданы или планируются, какие сферы интересны (десять категорий, которые
реально фильтруют каталог), бюджетное место или готовность платить, город,
язык обучения, форма обучения. Результат — каталог с уже выставленными
фильтрами. Регистрации нет, ничего не сохраняется — это сознательно
(экзаменационные результаты несовершеннолетних — самая чувствительная
категория данных в проекте).

### Калькулятор конкурсного балла

Один общий вычислитель (`src/lib/formula.ts`, ~80 строк) для всех вузов;
всё, чем вузы различаются, — данные в таблицах. Формула:

```
балл = Σ (результат_CE% × k_уровня × k_предмета_программы)
     + средний_% по всем CE × k_среднего
     + вклад аттестата
     + вступительное испытание × k
```

Коэффициенты уровня одинаковы у всех: `augstākais 1,00 · optimālais 0,75 ·
vispārīgais 0,50`. Шкалы у вузов разные (ЛУ — 1000, Вентспилс — около
100), поэтому баллы **несравнимы между вузами**; результат всегда с разбором
«из чего сложился балл», ссылкой на правила приёма и оговоркой, что решает
вуз. Формулы есть у 35 программ (Ventspils — 7, ЛУ — 26, РТУ — 2) и берутся
из **утверждённого PDF правил приёма**, а не со страницы сайта.

Публично калькулятор показывается только для формул с `verified_at`.

### Двухуровневое доверие

Каждый факт хранится с `source_url` и `verified_at`.

- **Только человек подтверждает** (правило 6): конкурсная формула, срок
  подачи, стоимость и бюджетные места, языковое требование, через кого
  подача. Автоприём запрещён, даже если два извлечения совпали. RLS
  не отдаёт неподтверждённые формулы наружу.
- **Черновики, видимые публично:** направление программы
  (`programme_field`) — нужно для фильтра «интересы», но без зарплатного
  блока, пока не подтверждено.
- Языковая модель **извлекает и объясняет, но не является источником
  факта**.

### Направления программ и выпускники

- **Источник статистики:** открытые данные IZM/ЦСУ (data.gov.lv, CC0) —
  «Latvijas augstākās izglītības iestāžu absolventi 2020–2024
  monitoringa gados». Ссылка на CSV — константа в
  `pipeline/src/graduate_outcomes.py`, обновляется вручную раз в год.
- **Чего данные не умеют:** доход скрыт у ~80% ячеек (нужно 30+
  занятых), у докторантов не публикуется никогда, это общий годовой
  доход только занятых, занятость — на ноябрь. Строки — «вуз × группа
  программ × уровень × год выпуска», поэтому блок говорит «выпускники
  направления», а не «выпускники программы».
- **Классификация направлений** — черновые правила по названию
  (`pipeline/src/programme_fields.py`), выбор из кандидатов идёт по
  данным; между разными профессиями запасных вариантов нет (лучше «нет
  данных», чем чужие зарплаты). Сейчас размечено 891 программа, 9 без
  правила, 162 — без данных для вуза/уровня.
- **Коды уровней** датасета (`Studiju_limenis`) официальной легенды не
  имеют; сопоставление сверено вручную: 41 колледж, 42/43/48/49
  бакалавриат, 45/47 магистратура, 51 докторантура.

## 5. Архитектура и стек

```
Next.js 16 (App Router, Turbopack)              Python + Playwright
  ├─ публичные страницы: серверный рендер,        │
  │  обычный Tailwind, без HeroUI                 │  скрейперы → pydantic → пишут
  ├─ интерактив (анкета, калькулятор,             │  напрямую в Postgres
  │  избранное): HeroUI v2 + клиентский JS        │  сервисным ключом
  └─ i18n: свои словари, без next-intl            │
                    └────────────┬───────────────┘
                                 ▼
                    Supabase (Postgres, ЕС, eu-west-1)
                    RLS на каждой таблице; anon key — у Next.js,
                    service_role — только у конвейера
```

| Слой | Что | Примечание |
|---|---|---|
| Веб | Next.js 16 (App Router), маршруты по локалям | SSR обязателен для публичных страниц |
| UI | HeroUI **v2** + Tailwind v4 | не v3 — API другой |
| БД, авторизация, файлы | Supabase (Postgres), регион ЕС | RLS без исключений |
| Конвейер данных | Python 3.13+: Playwright + pydantic | по расписанию в GitHub Actions |
| Платежи | Stripe Payment Links | только с выпуска 4 |
| Почта | Resend | напоминания про январь и июль (не подключено) |
| Аналитика | PostHog | воронка + Core Web Vitals (не подключено) |

Ключевые архитектурные решения:

1. **Многоязычность с первого коммита.** Тексты только в
   `src/i18n/dictionaries/lv.json` и `en.json`, в коде строк нет.
   Критичные поля в базе (дедлайн, стоимость, формула, язык обучения)
   языконезависимы. Локали: латышский и английский; **русский отменён**,
   эстонский и литовский — не раньше 2028.
2. **Формулы — данные, а не код** (таблицы `formula`, `formula_term`,
   `formula_gate`, `level_coefficient`).
3. **Граница Next.js / Python — по базе данных, не по HTTP.** Никакого
   FastAPI, CORS или второго сервиса.
4. **Публичные страницы лёгкие:** серверные компоненты на Tailwind без
   `"use client"`; HeroUI только там, где есть интерактив. Полируем
   страницу программы, а не главную — рост идёт из поиска.
5. **Чистая логика отдельно от обращений к базе** (`formula.ts` /
   `formula-queries.ts`, `catalog-view.ts` / `catalog-query.ts`,
   `outcomes.ts` / `outcome-queries.ts`) — чтобы тестировать без клиента
   Supabase.

## 6. Конвейер данных

`pipeline/src/main.py` запускает источники и пишет **черновики**
сервисным ключом; он никогда не трогает `verified_at` и `verified_by`, а
повторный запуск не затирает подтверждённые вручную поля (upsert).

- `python src/main.py` — все источники; `python src/main.py rsu lu` —
  только названные (по имени модуля).
- **Проверка полноты.** У каждого источника (у колледжей — у каждого
  колледжа отдельно) есть минимальное число программ (`MIN_PROGRAMME_COUNT`).
  Если найдено меньше — конвейер падает: раньше сборщик ЛУ однажды тихо
  потерял целый факультет и это заметили только при ручной сверке. Если
  число законно уменьшилось, порог поднимают вручную. Колледж, у которого
  есть порог, но который не вернул ни одной программы, — тоже сбой.
- **Вежливый обход** (`pipeline/src/polite.py`, подключён одной строкой в
  `main.py`): честный User-Agent `StudetBot/1.0 (+контакт из SCRAPER_CONTACT)`,
  пауза не меньше 1,5 с между страницами одного домена (у niid.lv по
  `robots.txt` — 10 с), запрещённые `robots.txt` адреса не открываются,
  картинки, шрифты и видео не грузятся (за полный прогон это ~19 тыс.
  лишних запросов), локальный кэш для отладки (`SCRAPE_CACHE=1`). Запуск по
  расписанию — ночью по Риге.
- **Один упавший источник не останавливает остальные:** сбои копятся,
  печатаются в конце, код возврата ненулевой.
- **Одна программа — одна строка** по ключу `(university_id, slug)`.
  Программы, исчезнувшие с сайта вуза, из базы **не удаляются** (конвейер
  только добавляет и обновляет).
- **Вспомогательные скрипты:** `seed_formulas.py`, `seed_deadlines.py`,
  `seed_admission_types.py`, `seed_programme_fields.py [--apply]`,
  `import_graduate_outcomes.py`. Каждый работает через upsert без
  `verified_at`.
- **Расписание:** `.github/workflows/scrape-catalog.yml` — по понедельникам
  06:00 UTC и вручную. Требует секреты `SUPABASE_URL` и
  `SUPABASE_SERVICE_ROLE_KEY` в GitHub (значение service_role в чат не
  передаётся).
- Скрапинг публичных источников ведётся без отдельной проверки условий
  использования — риск принят владельцем.

Зависимости Python: `playwright`, `pydantic`, `supabase`, `python-dotenv`.

## 7. Качество: безопасность, доступность, скорость

**Безопасность (OWASP Top 10:2025).**
- A01: RLS-политики на каждой таблице; неподтверждённые формулы и сроки не
  отдаются наружу.
- A02: сервисный ключ живёт только в окружении Python-конвейера; в бандл
  Next.js попадают только `NEXT_PUBLIC_SUPABASE_URL` и anon-ключ.
- A03: каждая зависимость обосновывается; «двадцать строк вместо
  библиотеки».
- A07: авторизация отдана Supabase, своей нет.

**Доступность (WCAG 2.2 AA, EAA).** Runtime-аудит axe-core + Playwright на
каждый push: 4 маршрута × 2 локали. Клавиатурный проход по новым экранам
делается перед релизом.

**Скорость (Core Web Vitals):** `LCP < 2,5 с`, `INP < 200 мс`, `CLS <
0,1`. Меряется на реальных пользователях (после подключения PostHog).
Фоновая картинка главной — WebP 35 КБ; в CI есть бюджет статики (файл в
`public/` не больше 300 КБ).

**CI (`ci.yml`, на каждый push в `master` и PR):** lint → 52 unit-теста
(vitest) → бюджет статики → сборка (нужны секреты
`NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`) → axe-аудит.

## 8. Как работать с проектом

```bash
npm run dev               # локальный сервер, http://localhost:3000
npm run build             # прод-сборка
npm run lint              # ESLint
npm run test              # unit-тесты (vitest)
```

Окружение фронтенда — `.env.local` (шаблон `.env.local.example`):
`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`,
`NEXT_PUBLIC_SITE_URL` (домен ещё не выбран, по умолчанию

```bash
cd pipeline
./.venv/Scripts/python.exe src/main.py            # все источники
./.venv/Scripts/python.exe src/main.py rsu lu     # выборочно
```

Схема — SQL-миграции в `supabase/migrations/`, применяются через
`npx supabase db push`. Разработка идёт только в облаке, без локального
Docker-стека (осознанный компромисс при 5 ч/нед).

Порядок работы (из `CLAUDE.md`): сначала план изменений, потом код;
маленькими шагами, одна фича — один понятный коммит; если можно проще
ценой небольшой потери качества — предлагать простое и говорить, чем
жертвуем; перед новой библиотекой — сколько весит и что будет без неё.

## 9. Известные ограничения и оговорки

- **Данные не подтверждены.** Все 899 программ помечены «извлечено
  автоматически»; формулы, окна подачи, типы отбора и направления ждут
  ручного подтверждения в Supabase Studio, иначе часть функций
  (калькулятор, сроки, зарплатный блок) не показывается — так задумано.
- **Не проверено на нескольких форматах страниц у других вузов.** У ЛУ
  выявлено три формата подписей полей; у РТУ и остальных такая проверка
  не проводилась.
- **Названия колледжей ЛУ** в каталоге — «Latvijas Universitātes …», у
  NIID они пишутся «LU …».
- **Названия только на одном языке** у некоторых вузов (JVLMA, LKA, LMA
  дают только английские названия) — на латышской версии показывается то,
  что есть.
- **Цена RAI и части колледжей** не разбирается или берётся только если
  явно указана «за год»; таблицы с несколькими тарифами дают пустое поле.
- **Язык программы у части вузов — предположение** (LKA, LMA, JVLMA,
  EKrA, LNAA: язык на сайте не указан, поставлен латышский).
- **Переключатель языка** сбрасывает фильтры каталога (сохраняет только
  страницу).
- **`funding_type='paid'`** для программ с финансированием церкви
  (Rīgas Teoloģijas institūts) — осторожный дефолт, отдельного значения
  в схеме нет.
- **SSE Riga и RGSL** записаны в базе как частные вузы, а в списке
  вузов владельца стоят среди «valsts augstskolas» — расхождение не
  разрешено.
- **Даты приёма 2027 не опубликованы** у ЛУ, РТУ и Turība (LV) на
  17 сентября 2026; сроки внесены только для Turība (английский приём).
- **Мониторинг источников в дни сезона** (9–20 июля 2027) вручную не
  подтверждён; скрипт снимков работает автономно круглый год.
- **Согласие несовершеннолетних на рассылку** (email-напоминания,
  выпуск 1) не проверено — проверить перед сбором почты.
- **Дисклеймер об ответственности** («независимый информационный
  портал, решает вуз») нужен к выпуску 2, когда появляется калькулятор;
  текст уже есть в словарях, но юридически не выверялся.
- Push из среды разработки с ассистентом иногда идёт очень долго (минуты)
  или требует пуша из своего терминала.
