# Гид по тестированию StudyPick

Один документ: как запустить сайт и что проверять на каждой странице — с
состоянием данных на **2026-10-30**, чтобы при проверке было понятно, где
настоящая ошибка, а где данные ещё не наполнены или не подтверждены. Цифры
сняты с живой базы и со временем разойдутся с ней; последний статус —
`docs/PLAN-2026-09-21.md`, раздел 10. Описание проекта целиком —
[`PROJECT.md`](./PROJECT.md).

Отметки «(с 2026-10-…)» — что изменилось недавно: их стоит проверить первыми.

## 0. Прежде чем тестировать

- **Сервер:** правки с 2026-10-25 (шрифт полей на телефоне) появятся там
  после `deploy/update.sh`. Проверять можно и локально — гид написан под
  локальный запуск.
- **Свежесть данных:** сбор 26 октября упал у шести источников (раздел 13в).
  У LBTU, ViA, RAI, LNAA и программ из NIID дата проверки на карточке — 19
  октября, у РТУ — 10-е, у LMA — 3-е. Это не ошибка сайта.
- **Автоматические проверки** покрывают то, что можно проверить без человека:

  | Команда | Что проверяет | На 2026-10-30 |
  |---|---|---|
  | `npm test` | расчёт балла, фильтры, разбор данных | 295 тестов |
  | `npm run build`, затем `npm run test:a11y` | axe на ~120 адресах, клавиатура, телефон (без прокрутки вбок, поля от 16 px), заголовки безопасности | 145 сценариев |
  | `npm run lint`, `npx tsc --noEmit` | линтер и типы | без ошибок |
  | `python src/run_selftests.py` в `pipeline/` | разбор страниц и документов, правила `robots.txt`, без сети и базы | 53 самопроверки |

  `test:a11y` работает с последней сборкой: без `npm run build` он проверяет
  старый код. Ручная проверка нужна для того, чего автоматика не видит:
  понятность текстов, логика, внешний вид.

## 1. Что это за проект (коротко)

Веб-сервис, помогающий выпускникам выбрать вуз: анкета → каталог →
калькулятор конкурсного балла → «куда можно поступить». Бесплатно, без
регистрации, результаты экзаменов не покидают браузер. Три страны: Латвия
(запуск 5 января 2027), Литва (1 июня 2027) и Эстония (даты нет) — обе
последние закрыты флагом предпросмотра. Четыре языка интерфейса у каждой
страны. Платный продукт для иностранцев сознательно не начат — об этом
полоса на английских страницах. Правила — `CLAUDE.md`.

## 2. Как запустить локально

```bash
npm install
cp .env.local.example .env.local
# заполнить NEXT_PUBLIC_SUPABASE_URL и NEXT_PUBLIC_SUPABASE_ANON_KEY
# значениями из Supabase Dashboard -> Settings -> API
npm run dev                 # http://localhost:3000
```

Рабочая сборка (так сайт работает на сервере; заголовки безопасности и
скорость — только в ней): `npm run build`, затем `npm run start`.

Флаги в `.env.local` (описание — в `.env.local.example`):
- `NEXT_PUBLIC_PREVIEW_COUNTRIES=1` — открывает Литву, Эстонию и эстонский
  язык (разделы 13а и 13б). Без флага открыты только `/lv`, `/lt-lv`,
  `/en-lv` — так будет на рабочем сайте 5 января.
- `MATCH_FIXTURE=1` — на `/match` выдуманные формулы для проверки вёрстки.
- `PRIVACY_CONTROLLER_NAME`, `PRIVACY_CONTACT_EMAIL` — без них `/privacy`
  показывает имя переменной вместо контакта (так и задумано).
- `FEEDBACK_EMAIL` — адрес ссылки «Pamanīji kļūdu? Raksti mums»; без него
  (и без `PRIVACY_CONTACT_EMAIL`) ссылки нет.
- Аналитика (`NEXT_PUBLIC_POSTHOG_KEY`) на localhost ничего не отправляет
  ни при каком ключе — это проверка рабочего сайта.
