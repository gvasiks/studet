# Сверка страницы «Права абитуриента» с нормами

Тексты страницы `/rights` написаны по дословным нормам ниже (likumi.lv, прочитаны
2026-09-20): MK noteikumi Nr. 846 (редакция на 30.12.2025) и Augstskolu likums.
Ваша задача перед публикацией — пройти по таблице: совпадает ли наш пересказ
с нормой. **Чего на странице нет намеренно:** пересказ ИЗМ про «запрет привлекать
студентов и заключать договоры до официальной даты» в этих текстах норм не найден
(в Augstskolu likums 46. pants и в MK Nr. 846 такого запрета нет; есть только:
договор — после документов и объявления результатов, дата начала регистрации —
в правилах вуза, п. 13.3.² MK). Пока формулировка нормы не найдена, страница
её не утверждает.
