# Проверка формулы РТУ на ваших настоящих результатах

Личный опыт поступления в РТУ формулой-источником не считается: это один год,
одна программа, а коэффициенты меняются. Но им можно **проверить понимание** —
если формула из базы на ваших настоящих результатах даёт то, что вышло у вас
тогда, значит, вы и мы понимаем структуру формулы одинаково. Расхождение —
знак ошибки, и найти её лучше сейчас, чем 27 июля.

## Что нужно от вас (15–20 минут)

1. Возьмите свои настоящие результаты поступления в РТУ: проценты ЦЭ по
   каждому предмету, **уровень** каждого экзамена (`augstakais`, `optimalais`,
   `vispaarigais`), при необходимости оценку аттестата и результаты
   вступительных испытаний, и **итоговый балл, который у вас вышел**.
2. Скопируйте `rtu-personal-check.example.json` в файл рядом (например,
   `my-rtu.json`, в git он не нужен) и замените числа на свои.
3. Запустите, указав вашу программу:

   ```
   npm run check:formula -- rtu <код-программы> docs/checks/my-rtu.json
   ```

   Скрипт читает ключ из `pipeline/.env` (он никуда не печатается) и ничего
   не пишет в базу.
4. Сравните «Итого по формуле из базы» со своим настоящим баллом. В конце
   скрипт сам напишет «Совпало» или «РАСХОЖДЕНИЕ».

## Важно знать

- **Формулы РТУ в базе только для двух программ** (Rīgas Biznesa skola):
  `ibx-02c60` (Vadīšana starptautiskos uzņēmumos) и `dbt-02c60` (Datorzinātne
  un organizāciju tehnoloģijas). Если вы поступали на другую программу, прямого
  сравнения не будет; тогда пришлите название программы и год, и посмотрим,
  добавлять ли её формулу.
- **Формула в базе — по правилам 2026/27** (Senāta protokollēmums Nr. 697,
  24.11.2025). Если вы поступали раньше, правила могли быть другими:
  расхождение в баллах тогда ожидаемо, и сравнивать надо с документом вашего
  года, а не с этой формулой.
- Если разница есть, запишите числа: результаты по предметам, уровни, ваш балл
  и балл скрипта. Этого достаточно, чтобы разобраться.
