# Снимки подтверждённых фактов

План 2026-09-21, неделя 1, пункт 06: самое дорогое в проекте — не код (он
и так в git), а часы владельца, потраченные на подтверждение формул, сроков,
типов отбора и направлений через Supabase Studio. На бесплатном тарифе
Supabase ежедневных резервных копий нет.

`verified-facts.json` — снимок всех записей с `verified_at is not null`
(формулы, сроки подачи, типы отбора, направления программ) на момент
последнего запуска `.github/workflows/backup.yml` (понедельник, 03:00 UTC).
Обновляется автоматически: `pipeline/src/backup_verified.py`, коммитится
самим workflow, если содержимое изменилось.

**Зачем коммитить, а не просто дампить в артефакт.** Артефакты прогонов
GitHub Actions живут ограниченный срок и не диффятся построчно. Здесь —
обычный файл в git: история изменений видна в `git log -- docs/backups/`,
случайное затирание подтверждения видно в PR-диффе, а восстановить 72
формулы можно **без единого запроса к базе**, если база вообще пропала.

**Чего здесь нет.** Черновики (не подтверждённые записи), сам каталог
программ, данные о выпускниках, ключи, пароли. Полный дамп всей схемы
`public` (включая черновики) уходит в артефакт прогона того же workflow
(`pg_dump`, нужен секрет `SUPABASE_DB_URL`), не в этот файл и не в git:
он больше, содержит то, что ещё не проверено человеком, и незачем хранить
его версии одну за другой.

## Ключи в JSON

Записи адресуются не по UUID (они не переживают пересоздание базы —
seed-скрипты генерируют новые id при каждом запуске), а по устойчивым
слагам: `university_slug` + `programme_slug`. Снимок можно прочитать и
сверить глазами, не разворачивая базу.

## Как восстановить

Формулы: по каждой записи найти программу по `(university_slug,
programme_slug)`, вставить `formula`/`formula_term`/`formula_gate` с теми
же полями, включая протокол источника, и в конце — `verified_at` /
`verified_by` из снимка. Отдельного скрипта на 2026-09-22 ещё нет
(план, неделя 2, пункт «06 конец»); до этого — вручную по структуре файла.

**Ежеквартально** стоит на самом деле развернуть снимок или дамп на чистый
проект и проверить, что это действительно работает — копия, которую ни разу
не разворачивали, копией не является.
