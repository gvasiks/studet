# pipeline

Конвейер сбора каталога: обходит сайты вузов и пишет черновики программ
в тот же Postgres, что использует Next.js — сервисным ключом, напрямую,
без HTTP-API между Python и Next.js (CLAUDE.md, правило 3).

## Важно: что конвейер не делает

Он никогда не проставляет `verified_at`/`verified_by` — эти поля видит
только человек через Supabase Studio (CLAUDE.md, правило 6). Всё, что
сюда попало, помечено как «извлечено автоматически» и требует сверки
перед тем как доверять ему при принятии решения о поступлении.
Повторный запуск не затирает уже подтверждённые вручную записи — `upsert`
просто не трогает поля, которых нет в присланной строке.

## Локальный запуск

```
py -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe -m playwright install chromium
```

Скопируйте `.env.example` в `.env` и заполните `SUPABASE_URL` /
`SUPABASE_SERVICE_ROLE_KEY` (Settings → API → service_role secret —
не anon, этот ключ обходит RLS).

```
./.venv/Scripts/python.exe src/main.py
```

## Расписание

`.github/workflows/scrape-catalog.yml` — по понедельникам, плюс запуск
вручную. Нужно добавить в GitHub secrets репозитория (Settings → Secrets
→ Actions) те же `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` — сделать
самостоятельно, сервисный ключ через чат передавать не стоит второй раз.

## Источники

Каждый вуз — свой модуль в `src/sources/`, с функцией `scrape() ->
(UniversityDraft, list[ProgrammeDraft])`. Структура страниц у вузов
разная, общего парсера не будет — см. `src/sources/turiba.py` как
образец: селекторы найдены и проверены вручную в браузере, не угаданы.

Сейчас источников — один (Turība, английский раздел, 17 программ).
Следующий вуз добавляется отдельным файлом + строкой в `SOURCES`
в `src/main.py`.

## Сознательно не собираем пока

- **Стоимость** — у Турибы это одна общая таблица на всех, не привязанная
  к конкретной программе URL-ом; парсить текстовую таблицу вслепую
  ненадёжнее, чем внести цифры руками в Studio.
- **Дедлайн подачи** — не нашёлся в структурированном виде per-programme.
- **Латышское название программы** — конвейер читает английский раздел
  сайта; `name_lv` для этих программ пока пустой, заполняется вручную.

Все три поля и так по правилу 6 подтверждает только человек — конвейер
не обязан их доставать, чтобы каталог был полезен.
